# 🌌 Planet Search

## ✨ Descrição Breve  
Uma aplicação que exibe uma lista de planetas do universo Star Wars, com filtros baseados em diversos critérios. Utilizando a **Context API** do React e **hooks** para controlar os estados globais, o projeto foi desenvolvido para aprender a gerenciar estados no React e escrever testes para garantir uma boa cobertura de código.

## 🚀 Como Rodar o Projeto  
1. Clone o repositório:  
   ```bash
   git clone https://github.com/Gzuuu/starwars-planet-search.git
   ```  
2. Acesse a pasta do projeto:  
   ```bash
   cd starwars-planet-search
   ```  
3. Instale as dependências:  
   ```bash
   npm install
   ```  
4. Inicie a aplicação:  
   ```bash
   npm start
   ```  
5. A aplicação estará disponível localmente para teste e uso.

## 🛠️ Tecnologias Utilizadas  
- **React**  
- **Context API**  
- **Hooks (useState, useContext, useEffect)**  
- **React Testing Library**  

## ⚙️ Funcionalidades  
- 🌍 Exibir uma lista de planetas do universo Star Wars.  
- 🔍 Filtros dinâmicos para buscar planetas por diferentes critérios.  
- ⚡ Utilizar **Context API** para gerenciar estados globais.  
- 🧪 Garantir cobertura de código com testes usando React Testing Library.  

## 📚 Principais Aprendizados  
- Gerenciamento de estados no **React** com **Context API**.  
- Uso dos hooks **useState**, **useEffect** e **useContext**.  
- Criação de **React Hooks customizados**.  
- Escrever **testes** para garantir cobertura de código e qualidade da aplicação.
